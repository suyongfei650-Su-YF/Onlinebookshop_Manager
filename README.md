## 1. 项目背景与目标

### 1.1 背景

随着互联网技术的快速发展和电子商务的普及，网上购物已成为人们日常生活中不可或缺的一部分。传统的实体书店面临着租金成本高、营业时间受限、客户覆盖面窄等问题，迫切需要通过线上渠道拓展业务。

图书作为一种传统的知识载体，具有标准化程度高、售后简单、物流成熟等特点，非常适合电子商务销售模式。然而，市场上现有的书城系统普遍存在以下痛点：

- **用户体验差**：页面加载缓慢，交互不友好
- **功能单一**：缺乏完善的购物车、订单跟踪等功能
- **管理效率低**：后台管理界面简陋，无法满足日常运营需求
- **扩展性差**：系统架构老旧，难以二次开发和功能扩展

基于以上行业痛点，开发一套功能完善、操作便捷、界面美观的网上书城购物系统具有重要的现实意义。

### 1.2 目标

本项目旨在设计并实现一个基于 Web 的网上书城购物系统，具体目标如下：

1. **用户购物目标**
   - 为用户提供便捷的图书浏览、搜索、购买服务
   - 实现购物车、订单管理、收藏等完整的购物流程
   - 支持多种登录方式（账号密码、微信登录）

2. **管理运营目标**
   - 为管理员提供高效的图书、订单、用户管理功能
   - 实现销售数据统计和可视化展示
   - 支持图书封面上传和管理

3. **技术实现目标**
   - 采用前后端分离架构，提高系统可维护性和扩展性
   - 使用现代化的技术栈，确保系统的稳定性和性能
   - 保证代码结构清晰，便于后续功能扩展

## 4. 详细设计

### 4.1 前台用户模块设计

#### 4.1.1 首页展示

- **功能描述**：展示新书上架、热门推荐等图书信息
- **页面组件**：`PortalHomeView.vue`
- **API 接口**：`/api/portal/books`

#### 4.1.2 购物车

- **功能描述**：管理用户购物车中的商品
- **页面组件**：`UserCartView.vue`
- **API 接口**：
  - `GET /api/user/cart` - 获取购物车
  - `POST /api/user/cart` - 添加商品
  - `PUT /api/user/cart/{id}` - 修改数量
  - `DELETE /api/user/cart/{id}` - 删除商品

#### 4.1.3 订单管理

- **功能描述**：创建和查看用户订单
- **页面组件**：`UserCheckoutView.vue`、`UserOrdersView.vue`
- **API 接口**：
  - `POST /api/user/orders` - 创建订单
  - `GET /api/user/orders` - 获取订单列表
  - `GET /api/user/orders/{id}` - 获取订单详情

### 4.2 后台管理模块设计

#### 4.2.1 图书管理

- **功能描述**：对图书进行增删改查操作
- **页面组件**：`AdminBooksView.vue`
- **API 接口**：
  - `GET /api/admin/books` - 获取图书列表
  - `POST /api/admin/books` - 添加图书
  - `PUT /api/admin/books/{id}` - 更新图书
  - `DELETE /api/admin/books/{id}` - 删除图书

#### 4.2.2 订单管理

- **功能描述**：管理用户订单，更新订单状态
- **页面组件**：`AdminOrdersView.vue`
- **API 接口**：
  - `GET /api/admin/orders` - 获取订单列表
  - `GET /api/admin/orders/{id}` - 获取订单详情
  - `PUT /api/admin/orders/{id}/status` - 更新订单状态

#### 4.2.3 数据统计

- **功能描述**：展示销售数据统计和热门图书排行
- **页面组件**：`AdminDashboardView.vue`
- **API 接口**：`GET /api/admin/dashboard`

### 4.3 核心业务流程设计

#### 4.3.1 购物流程

1. 用户浏览图书
2. 用户将图书加入购物车
3. 用户查看购物车
4. 用户确认订单信息
5. 用户提交订单
6. 系统创建订单并扣减库存
7. 用户完成支付（可选）
8. 管理员处理订单

#### 4.3.2 管理流程

1. 管理员登录系统
2. 管理员查看仪表盘数据
3. 管理员进行图书/订单/用户管理
4. 管理员退出系统

## 6. 系统安全设计

### 6.1 认证机制

- 基于 Session 的认证方式
- 登录时生成验证码防止暴力破解

### 6.2 权限控制

- 前台用户和后台管理员使用不同的认证体系
- 路由守卫保护需要登录才能访问的页面
- 后端拦截器验证用户登录状态

### 6.3 数据安全

- 用户密码加密存储
- 防止 SQL 注入（使用 MyBatis-Plus 参数化查询）
- 防止 XSS 攻击（前端进行输入过滤）

## 7. 部署说明

### 7.1 环境要求

- JDK 1.8+
- Node.js 16+
- MySQL 5.7+
- Tomcat 9+（可选，也可使用 Spring Boot 内置 Tomcat）

### 7.2 部署步骤

1. **后端部署**
   - 创建数据库并导入初始数据
   - 修改数据库配置文件
   - 使用 Maven 打包项目：`mvn clean package`
   - 部署 WAR 包到 Tomcat 或直接运行 JAR

2. **前端部署**
   - 安装依赖：`npm install`
   - 构建生产版本：`npm run build`
   - 将 `dist` 目录部署到 Web 服务器

## 8. 总结

本项目成功实现了一个功能完善的网上书城购物系统，采用前后端分离的现代化架构设计。系统包含前台用户购物模块和后台管理模块，涵盖了图书浏览、购物车、订单管理、用户管理、统计分析等核心功能。

通过本项目的开发，深入学习了 Spring Boot 框架、Vue 3 框架以及 MyBatis-Plus ORM 工具的使用，掌握了前后端分离架构的设计与实现方法，提高了面向对象编程能力和问题解决能力。

项目在功能完整性和用户体验方面达到预期目标，但在性能优化、安全加固等方面仍有改进空间，未来可通过引入缓存、优化架构等方式进一步提升系统能力。
