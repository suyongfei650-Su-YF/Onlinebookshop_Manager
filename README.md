# 网上书城购物系统 - 项目说明书

## 一、项目概述

### 1.1 项目基本信息

| 项目名称 | 网上书城购物系统 |
|----------|------------------|
| 项目类型 | 模拟企业场景实训项目 |
| 项目来源 | 学生自主选择 |
| 技术架构 | 前后端分离（Spring Boot + Vue 3） |
| 开发状态 | 已完成核心功能开发与测试 |
| 完成日期 | 2026年5月 |

### 1.2 项目背景

随着互联网技术的快速发展和电子商务的普及，网上购物已成为人们日常生活中不可或缺的一部分。传统实体书店面临租金成本高、营业时间受限、客户覆盖面窄等问题，迫切需要通过线上渠道拓展业务。

图书作为标准化程度高、售后简单、物流成熟的商品品类，非常适合电子商务销售模式。本系统旨在为用户提供便捷、安全、高效的购书体验，同时为商家提供完善的后台管理功能。

### 1.3 项目目标

| 目标类别 | 具体目标 |
|---------|----------|
| 用户购物 | 图书浏览、搜索、购物车、订单管理、收藏功能 |
| 管理运营 | 图书管理、订单管理、用户管理、数据统计可视化 |
| 技术实现 | 前后端分离、RESTful API、响应式设计 |

## 五、核心业务流程

### 5.1 用户购物流程

```
用户浏览图书 → 搜索/筛选 → 查看详情 → 加入购物车
    ↓
查看购物车 → 修改数量 → 确认订单 → 提交订单
    ↓
系统扣减库存 → 创建订单 → 用户查看订单状态
    ↓
管理员发货 → 用户确认收货 → 订单完成
```

### 5.2 AI助手交互流程

```
用户提问 → 前端发送请求 → 后端AI服务调用 → AI生成回复 → 返回结果
    ↓
用户选择推荐图书 → 跳转图书详情页 → 加入购物车
```

### 5.3 库存预警流程

```
定时任务检查库存 → 库存低于阈值 → 生成预警记录 → 通知管理员
    ↓
管理员查看预警 → 补充库存 → 更新预警状态
```

{

```
GET /api/portal/books?categoryId=&page=&size=&sort=

```

## 十、部署说明

### 10.1 环境要求

| 依赖 | 版本 |
|------|------|
| JDK | 1.8+ |
| Node.js | 16+ |
| MySQL | 5.7+ |

### 10.2 部署步骤

**后端部署**：
```bash
# 1. 创建数据库
mysql -u root -p -e "CREATE DATABASE bookshop_db;"

# 2. 修改配置
# 编辑 src/main/resources/application.yml

# 3. 打包运行
mvn clean package
java -jar target/bookshop-admin-0.0.1-SNAPSHOT.jar
```

**前端部署**：
```bash
cd manager-ui
npm install
npm run build
# 将dist目录部署到Web服务器
```

### 10.3 快速启动

项目提供IDEA运行配置：
- `后端_Spring_Boot`：启动后端服务（8080端口）
- `前端_manager_ui_dev`：启动前端开发服务器（5173端口）
