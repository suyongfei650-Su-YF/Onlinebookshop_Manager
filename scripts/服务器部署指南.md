# 馆藏书屋 — 从零到域名上线完整指南

面向毕业设计/答辩演示：从**买服务器、买域名、装环境、上传项目**到用 **https://你的域名.com** 访问。

---

## 零、部署前要准备什么

| 物品 | 说明 | 是否必须 |
|------|------|----------|
| 云服务器（ECS） | 有公网 IP 的 Linux 虚拟机 | **必须** |
| 域名 | 如 `bookshop.example.com` | 域名访问必须；仅用 IP 可暂不购买 |
| 域名备案 | 服务器在中国大陆时，域名需 ICP 备案后才能用 80/443 | 国内服务器 **必须** |
| 本机 Windows | 用于 Maven 打包 WAR、npm 打包前端 | **必须** |
| JDK 8（本机） | 运行 `scripts\build-war-java8.bat` | **必须** |
| 远程工具 | SSH（命令行）+ 文件上传（WinSCP / FileZilla） | 强烈建议 |

**推荐配置（学生机够用）：**

| 项目 | 建议 |
|------|------|
| CPU / 内存 | **2 核 4GB**（最低 2核2G，内存紧张时给 MySQL 少配点） |
| 系统盘 | 40GB SSD |
| 操作系统 | **Ubuntu 22.04 64位**（下文命令均按 Ubuntu 写） |
| 带宽 | 3～5 Mbps 按量或固定带宽均可 |
| 地域 | 选离自己近的（如华东、华南） |

**费用粗算（新用户活动价，仅供参考）：**

| 项目 | 大约 |
|------|------|
| 云服务器 | 学生机约 **9～100 元/年**；普通轻量约 **50～200 元/年** |
| 域名 `.com` | **50～80 元/年** |
| 备案 | **免费**（需 1～20 个工作日） |
| HTTPS 证书 | **免费**（Let’s Encrypt） |

## 一、整体流程（按顺序做）

```
① 购买云服务器 → ② 购买域名（可选先买）→ ③ 域名备案（国内机房）
       ↓
④ SSH 登录服务器 → ⑤ 安装 JDK8 / MySQL / Tomcat / Nginx
       ↓
⑥ 导入数据库 sql/bookshop_admin.sql
       ↓
⑦ 本机打包 WAR + 前端 dist → ⑧ 上传到服务器
       ↓
⑨ 配置 Tomcat、启动后端 → ⑩ 配置 Nginx + 域名解析
       ↓
⑪ 申请 HTTPS → ⑫ 浏览器访问 https://你的域名.com/portal
```

**架构说明（答辩可画这张图）：**

```
                    ┌─────────────────────────────────┐
  用户浏览器  ──►   │  Nginx :80 / :443               │
                    │  · 静态页 = Vue dist            │
                    │  · /api → 反代 Tomcat           │
                    └────────────┬────────────────────┘
                                 │
                    ┌────────────▼────────────────────┐
                    │  Tomcat :8080（仅本机访问）      │
                    │  /Onlinebookshop_Manager/*.war  │
                    └────────────┬────────────────────┘
                                 │
                    ┌────────────▼────────────────────┐
                    │  MySQL :3306（仅本机访问）       │
                    │  库名 bookshop_admin            │
                    └─────────────────────────────────┘
```

## 二、购买云服务器（以阿里云为例，腾讯云/华为云类似）

### 2.1 注册与实名

1. 打开 [阿里云](https://www.aliyun.com) / [腾讯云](https://cloud.tencent.com) / [华为云](https://www.huaweicloud.com)
2. 注册账号并完成**实名认证**（个人身份证即可，学生可做学生认证）

### 2.2 选购 ECS 云服务器

**阿里云路径示例：** 控制台 → 云服务器 ECS → 创建实例

| 配置项 | 怎么选 |
|--------|--------|
| 付费模式 | 包年包月（学生选「学生机」更便宜） |
| 地域 | 华东、华南等，**创建后不好改** |
| 镜像 | **Ubuntu 22.04 64位** |
| 实例规格 | 2核4G 或「轻量应用服务器」2核2G～4G |
| 系统盘 | 40GB ESSD/SSD |
| 公网 IP | **分配公网 IPv4**（必须） |
| 带宽 | 按使用流量 或 3Mbps 固定带宽 |
| 登录方式 | 推荐 **自定义密码**（记下 root 密码）或 SSH 密钥 |

创建完成后，在实例列表记下：

- **公网 IP**：如 `47.96.xxx.xxx`（域名解析、SSH 都用它）
- **内网 IP**：一般不用管

### 2.3 配置安全组（非常重要）

在实例 → **安全组** → 入方向规则，至少添加：

| 端口 | 协议 | 授权对象 | 用途 |
|------|------|----------|------|
| 22 | TCP | 你的办公网 IP 或 0.0.0.0/0 | SSH 远程（答辩演示可临时 0.0.0.0/0，用完改回） |
| 80 | TCP | 0.0.0.0/0 | HTTP 网站 |
| 443 | TCP | 0.0.0.0/0 | HTTPS |

**不要**对公网开放 **3306（MySQL）**、**8080（Tomcat）**，由 Nginx 在本机转发即可。

腾讯云叫「防火墙」，华为云叫「安全组」，规则同上。

## 三、购买域名与备案

### 3.1 买域名

在阿里云 **万网**、腾讯云 **DNSPod** 等购买，例如：

- `yourname-bookshop.cn`（`.cn` 需备案）
- `yourname.com`

购买后进入 **域名控制台 → 解析**，先不配，等服务器 IP 确定后再加 **A 记录**（见第十节）。

### 3.2 备案（服务器在中国大陆必须做）

1. 在云厂商控制台打开 **ICP 备案**
2. 按向导填写：主体（个人）、网站名称（如「馆藏书屋毕业设计演示」）、服务器 IP
3. 上传身份证、核验照片，等待管局审核（通常 **3～20 个工作日**）
4. **备案通过前**：域名不能正式用 80 端口对外提供网站；可先用 **服务器公网 IP +  hosts 本机测试**，或备案期间用 **非 80 端口**（不推荐答辩）

**仅答辩、不绑域名：** 可直接用 `http://公网IP/portal`（配好 Nginx 后），无需备案域名。

## 四、连接服务器

### 4.1 Windows 用 SSH

**PowerShell 或 CMD：**

```bash
ssh root@你的公网IP
# 首次会问 yes/no，输入创建实例时设的 root 密码
```

### 4.2 上传文件（WinSCP 推荐）

1. 下载安装 [WinSCP](https://winscp.net/)
2. 协议 SFTP，主机 = 公网 IP，用户 root，密码同 SSH
3. 左侧本机、右侧服务器，拖拽上传：
   - `Onlinebookshop_Manager.war`
   - `bookshop_admin.sql`
   - 整个 `dist` 文件夹
   - `book-covers` 封面目录（若有）

## 五、在服务器上安装运行环境（Ubuntu 22.04）

以下命令均在 **SSH 登录后** 执行（`root` 或 `sudo`）。

### 5.1 更新系统

```bash
apt update && apt upgrade -y
apt install -y curl wget unzip vim
```

### 5.2 安装 JDK 8

```bash
apt install -y openjdk-8-jdk
java -version
# 应看到 1.8.0_xxx
```

设置默认 Java（若系统有多个版本）：

```bash
update-alternatives --config java
# 选 java-8 对应编号
```

### 5.3 安装 MySQL 8

```bash
apt install -y mysql-server
systemctl enable mysql
systemctl start mysql
```

设置 root 密码并加固（按提示操作）：

```bash
mysql_secure_installation
# 设置 root 密码、移除测试库等，按 Y 即可
```

### 5.4 安装 Tomcat 9

```bash
cd /opt
wget https://archive.apache.org/dist/tomcat/tomcat-9/v9.0.93/bin/apache-tomcat-9.0.93.tar.gz
tar -xzf apache-tomcat-9.0.93.tar.gz
mv apache-tomcat-9.0.93 tomcat9
```

配置 Tomcat 使用 JDK 8，创建 `setenv.sh`：

```bash
cat > /opt/tomcat9/bin/setenv.sh << 'EOF'
export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
export JRE_HOME=$JAVA_HOME/jre
# 数据库（与 application-local.yml 二选一，这里用环境变量示例）
export MYSQL_URL="jdbc:mysql://127.0.0.1:3306/bookshop_admin?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8&allowPublicKeyRetrieval=true"
export MYSQL_USER="bookshop"
export MYSQL_PASSWORD="请改成你的强密码"
EOF
chmod +x /opt/tomcat9/bin/setenv.sh
```

**仅本机监听 8080**（不对公网暴露）：

编辑 `/opt/tomcat9/conf/server.xml`，找到 Connector `port="8080"`，增加或确认：

```xml
address="127.0.0.1"
```

创建 systemd 服务（开机自启）：

```bash
cat > /etc/systemd/system/tomcat9.service << 'EOF'
[Unit]
Description=Apache Tomcat 9
After=network.target mysql.service

[Service]
Type=forking
Environment=JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
ExecStart=/opt/tomcat9/bin/startup.sh
ExecStop=/opt/tomcat9/bin/shutdown.sh
User=root
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable tomcat9
```

### 5.5 安装 Nginx

```bash
apt install -y nginx
systemctl enable nginx
systemctl start nginx
```

浏览器访问 `http://你的公网IP`，应看到 Nginx 默认欢迎页。

## 六、部署数据库

### 6.1 上传并导入 SQL

用 WinSCP 把项目里的 `sql/bookshop_admin.sql` 传到服务器 `/root/`，然后：

```bash
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS bookshop_admin DEFAULT CHARSET utf8mb4;"
mysql -u root -p bookshop_admin < /root/bookshop_admin.sql
```

### 6.2 创建业务账号

```bash
mysql -u root -p
```

```sql
CREATE USER 'bookshop'@'localhost' IDENTIFIED BY '你的强密码_请修改';
GRANT ALL PRIVILEGES ON bookshop_admin.* TO 'bookshop'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

把上面密码同步到 Tomcat 的 `setenv.sh` 里 `MYSQL_PASSWORD`，或见下节 `application-local.yml`。

### 6.3 初始管理员账号

导入 SQL 后默认有：

| 用户名 | 密码 | 说明 |
|--------|------|------|
| admin | admin123 | **上线后请立刻在后台修改密码** |

## 七、本机（Windows）打包项目

在**你自己的电脑**上操作，不要直接在服务器里编译 Java（路径含中文易出问题）。

### 7.1 打包后端 WAR

```bat
cd 项目根目录\Onlinebookshop_Manager
scripts\build-war-java8.bat
```

成功得到：`target\Onlinebookshop_Manager.war`

### 7.2 生产配置（打包前可选）

在 `src\main\resources\` 新建 **`application-local.yml`**（不要提交 Git 里的真实密码）：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/bookshop_admin?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8&allowPublicKeyRetrieval=true
    username: bookshop
    password: 与服务器上一致的密码

app:
  admin:
    allow-register: false
  book-covers-dir: /data/bookshop/book-covers
```

若用此文件打包，WAR 内会带上配置；也可只靠 Tomcat `setenv.sh` 环境变量。

### 7.3 打包前端

```bat
cd manager-ui
npm install
npm run build
```

产物：`manager-ui\dist\` 整个文件夹。  
已配置 `manager-ui\.env.production`，API 前缀为 **`/api`**（与 Nginx 同域）。

## 八、上传并部署后端（Tomcat）

### 8.1 目录准备

```bash
mkdir -p /data/bookshop/book-covers
mkdir -p /var/www/bookshop
```

用 WinSCP 上传：

| 本机 | 服务器 |
|------|--------|
| `target\Onlinebookshop_Manager.war` | `/opt/tomcat9/webapps/Onlinebookshop_Manager.war` |
| `src\main\webapp\book-covers\*`（若有） | `/data/bookshop/book-covers/` |

### 8.2 启动 Tomcat

```bash
# 若已有旧版，先停
systemctl stop tomcat9
rm -rf /opt/tomcat9/webapps/Onlinebookshop_Manager
rm -f /opt/tomcat9/webapps/Onlinebookshop_Manager.war
# 重新上传 war 后再启

systemctl start tomcat9
# 查看日志
tail -f /opt/tomcat9/logs/catalina.out
```

### 8.3 验证后端（在服务器上）

```bash
curl -s "http://127.0.0.1:8080/Onlinebookshop_Manager/api/portal/categories" | head -c 200
```

应看到 `{"success":true,...}` 之类 JSON。若失败：查 MySQL 是否启动、密码是否正确、`catalina.out` 报错。

## 九、部署前端（Nginx 静态站）

### 9.1 上传 dist

把本机 `manager-ui\dist\` **里面所有文件**（含 `index.html`、`assets`）上传到：

```text
/var/www/bookshop/dist/
```

### 9.2 Nginx 站点配置

```bash
vim /etc/nginx/sites-available/bookshop.conf
```

写入（**把 `你的域名.com` 改成自己的；暂只有 IP 可写 `_` 或 IP**）：

```nginx
server {
    listen 80;
    server_name 你的域名.com www.你的域名.com;

    root /var/www/bookshop/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080/Onlinebookshop_Manager/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /book-covers/ {
        proxy_pass http://127.0.0.1:8080/Onlinebookshop_Manager/book-covers/;
        proxy_set_header Host $host;
    }
}
```

启用站点：

```bash
ln -sf /etc/nginx/sites-available/bookshop.conf /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t
systemctl reload nginx
```

### 9.3 仅用 IP 测试（备案前）

`server_name` 可写成 `_ ;`，浏览器访问：

```text
http://你的公网IP/portal
http://你的公网IP/admin/login
```

## 十、域名解析

域名**备案通过后**，到域名控制台 → **解析设置**：

| 记录类型 | 主机记录 | 记录值 |
|----------|----------|--------|
| A | @ | 服务器公网 IP |
| A | www | 服务器公网 IP |

等待几分钟～几小时生效，访问：`http://你的域名.com/portal`

## 十三、日常更新怎么发布

1. 本机改代码 → `scripts\build-war-java8.bat` → WinSCP 覆盖 `webapps\Onlinebookshop_Manager.war` → `systemctl restart tomcat9`
2. 前端改 UI → 本机 `npm run build` → 覆盖 `/var/www/bookshop/dist`
3. 只改 Nginx → `nginx -t && systemctl reload nginx`

## 十四、常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 外网打不开 80 | 安全组未放行 / 备案未过 | 查安全组 80、443；国内域名需备案 |
| 页面白屏 | dist 未传全或路径错 | 确认 `root` 指向含 `index.html` 的目录 |
| API 404 | Nginx 反代路径错 | `proxy_pass` 必须含 `Onlinebookshop_Manager` |
| 登录后马上退出 | 跨域或 API 地址错 | 前端必须用同域 `/api`，勿访问 `:8080` |
| Tomcat 起不来 | MySQL 连不上 | 查密码、`bookshop_admin` 是否导入 |
| class 55.0 | WAR 用 JDK11 编译 | 本机用 **JDK8** 重新 `build-war-java8.bat` |
| 封面 404 | 目录未上传 | 上传 `book-covers` 到 `/data/bookshop/book-covers` |

**总结：** 买一台 **2核4G Ubuntu 云服务器** → 安全组放行 **22/80/443** → 装 **JDK8 + MySQL + Tomcat + Nginx** → 导入 SQL → 本机打 WAR 和 dist 上传 → Nginx 反代 `/api` → 域名解析 + 备案 + HTTPS。按本文从第二节做到第十二节即可完整上线。
